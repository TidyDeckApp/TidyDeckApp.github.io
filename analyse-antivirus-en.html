If Windows SmartScreen warns you

This is normal for software signed by nobody: SmartScreen does not know the file's reputation yet, it is not saying “virus”. Check the fingerprint above first, then More info → Run anyway. Engine false positives against a utility that reads the registry and clears caches are well documented: the code is public, every line is verifiable.
