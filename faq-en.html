Frequently asked questions

Short answers. For everything else, the code is open and the app's log shows everything it does.

Trust and safety

Is TidyDeck free?

Yes, and it will stay that way. It is released under the GPL-3.0 licence: you can read the code, modify it and share it. A donation is possible, never required.

How can I be sure the file is safe?

Three checks that complement each other: the SHA-256 hash (it proves your file is identical to the one published), the VirusTotal scan (a snapshot at a given moment) and the open source code, which anyone can read. The links are on the download page.

Windows shows "Windows protected your PC". Is that normal?

Yes, for a small piece of software that is not yet digitally signed. This protection (SmartScreen) is wary of programs it does not know yet, without saying they are dangerous. A digital signature costs money, and this project is free.

If you have checked the SHA-256 hash, click "More info", then "Run anyway". If the hash does not match, do not run the file.

My antivirus flags it. What should I do?

This can happen with any small, recent program; it is called a false positive. Check the hash first, then look at the VirusTotal report. If an antivirus blocks it, report it on the "Report an issue" page: we will send it to the antivirus vendor for correction.

Does it collect data?

No. No account, no sign-up, no telemetry. Nothing leaves your PC. The only network access is the "Mises à jour" (check for updates) button: on click, it checks the published version and offers to open the download page. Nothing is ever downloaded or installed on its own.

Do I need to be an administrator?

No, not to start. Windows only asks for administrator rights if you use a feature that truly needs them (some services, the restore point), and it is Windows itself that asks you.

Day to day

What exactly does it clean?

Temporary files and caches. Each line tells you what it is, where it is and the risk level, with a button to open the location. There is no registry cleaner and no "boost".

Can I undo?

Yes, except for one thing. Cleaned files are moved to quarantine for 7 days by default and you can restore them from the "Journaux" (logs) page. Startup programs are disabled, not deleted. The only exception is emptying the Recycle Bin: it is immediate and permanent.

What does "Calmer Windows" (Quiet Windows) do?

It reduces suggestions, recommended apps and "Discover Windows" style messages, by changing your user settings only. Every setting can be undone: uncheck it and confirm.

What is "Les plus gros fichiers" (largest files)?

The list of the largest files and folders, in read-only mode. TidyDeck looks and shows you; it deletes nothing at this stage.

What are the modes for?

Serenity simplifies the interface and the wording. Advanced shows everything and adds options. Colorblind never uses color alone to show a state. Discreet hides your username, the PC name and personal paths on screen, handy when streaming.

Installing and leaving

How do I install it?

There is nothing to install: unzip the folder anywhere and run TidyDeck.exe. If you prefer a proper installer, one also exists in the project files.

How do I uninstall it?

Close TidyDeck (taskbar icon, then Quit) and delete its folder. To erase everything, also delete %LOCALAPPDATA%\TidyDeck.

Before deleting: anything still in quarantine disappears with the folder, so recover what you want to keep. The "Calmer Windows" settings already applied stay applied: uncheck them first if you want to go back.

Which versions of Windows are supported?

Windows 10 and Windows 11.

Where can I report a problem or suggest an idea?

On the project's issues page. Describe what you did, what you expected and what happened. A screenshot helps a lot.
